QUESTION 1: HADOOP MAPREDUCE KEYWORD SEARCH

This folder contains the implementation of a Hadoop MapReduce program in R.

Contents:
- Mapper.R
- Reducer.R
- Hadoop configuration settings
- Jupyter Notebook
- Screenshots of execution
- Question 1 report

Objective:
To perform dynamic keyword searching using the MapReduce framework and generate keyword frequency counts.

QUESTION 2: TOPIC MODELLING USING LDA

This folder contains the implementation of Latent Dirichlet Allocation (LDA) for topic modelling.

Contents:
- Topic modelling notebook
- news.zip dataset
- LDA output files
- Visualisations
- Question 2 report

Objective:
To identify major topics from a collection of news documents and visualise the most important keywords per topic.
